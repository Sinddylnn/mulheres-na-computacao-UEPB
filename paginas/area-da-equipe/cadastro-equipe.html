1 · Acesso

Só funciona para quem é colaboradora do repositório do site. O token é usado apenas nesta aba e enviado somente ao GitHub. É o mesmo token da página de envio de fotos.

Conectada como .

Como criar o seu token
  1. Peça a uma mantenedora para adicionar a sua conta do GitHub como colaboradora do repositório e aceite o convite recebido por e-mail.
  2. Abra a página de criação de token do GitHub. O nome e a permissão public_repo já vêm preenchidos.
  3. Escolha uma validade (por exemplo, 90 dias) e clique em Generate token.
  4. Copie o token e cole no campo acima. Guarde-o num gerenciador de senhas; o GitHub não mostra o token de novo.

Nunca compartilhe o token: ele dá acesso de escrita aos seus repositórios públicos. Se ele vazar, apague-o em Settings → Developer settings → Tokens.
